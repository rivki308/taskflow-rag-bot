# תפקידים והרשאות – TaskFlow Pro

## טבלת הרשאות

| פעולה | מנהלת | עובדת |
|---|---|---|
| התחברות למערכת | כן | כן |
| צפייה בכל המשימות | כן | לא |
| צפייה במשימות ששויכו אליה | כן | כן |
| יצירת משימה | כן | לא |
| עריכת פרטי משימה (כותרת, תיאור, עדיפות, תאריך יעד, שיוך, פרויקט) | כן | לא |
| שינוי סטטוס של משימה | כן, בכל משימה | כן, רק במשימות שלה |
| מחיקת משימה | כן | לא |
| צפייה בהערות והוספת הערה | כן, בכל משימה | רק במשימות שלה |
| צפייה בפרויקטים | כל הפרויקטים | רק פרויקטים שיש בהם משימה ששויכה אליה |
| יצירה ועריכה של פרויקטים | כן | לא |
| צפייה ברשימת העובדים והוספת עובד | כן | לא |

## מה עובדת יכולה לעשות
- לראות רק את המשימות ששויכו אליה.
- לצפות בפרטים של המשימות שלה.
- לשנות את הסטטוס של המשימות שלה, ורק את הסטטוס. כל שדה אחר נחסם.
- לקרוא ולהוסיף הערות במשימות שלה.

בגרסה הנוכחית עובדת לא יכולה ליצור משימות, למחוק משימות, לנהל עובדים או לנהל פרויקטים.

## איך ההרשאות נאכפות
- כל ההרשאות נבדקות בשרת בכל בקשה. הסתרת כפתור במסך היא רק לנוחות, ולא היא שמונעת את הפעולה.
- עובדת לא יכולה לצפות במשימה של עובדת אחרת גם אם תשנה את המספר בכתובת. במקרה כזה מופיעה ההודעה "אין לך הרשאה לבצע פעולה זו."
- עובדת שמנסה להיכנס למסך "עובדים" מועברת ללוח הבקרה.
- אי אפשר לשנות דרך המערכת את מי שיצר משימה או פרויקט. השדה הזה נקבע אוטומטית לפי המשתמש המחובר.
- משתמש לא יכול לשנות לעצמו את התפקיד.

## למי אפשר לשייך משימה
משימה אפשר לשייך רק למשתמש מסוג עובדת. אי אפשר לשייך משימה למנהלת.
