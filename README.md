# עוזר TaskFlow Pro – בוט ידע ארגוני (RAG)

בוט תמיכה למערכת TaskFlow Pro לניהול משימות בצוות. הבוט עונה על שאלות **רק** מתוך מסמכי המערכת שבתיקייה `data`, ועל שאלה שאין לה תשובה במסמכים הוא עונה "אין לי מידע על כך במסמכי המערכת."

## הידע הארגוני

| מסמך | נושא |
|---|---|
| `01-מדריך-התחלה.md` | התחברות, משך התחברות, התנתקות, תפריט |
| `02-תפקידים-והרשאות.md` | מנהלת מול עובדת, אכיפת הרשאות |
| `03-ניהול-משימות.md` | שדות, סטטוסים, עדיפויות, איחור, חיפוש, סינון ומיון |
| `04-פרויקטים.md` | שדות, סטטוסים, כלל התאריכים |
| `05-עובדים.md` | הוספת עובד, כללי סיסמה |
| `06-לוח-בקרה-והערות.md` | נתוני לוח הבקרה, הערות למשימה |
| `07-שאלות-נפוצות-ותקלות.md` | הודעות שגיאה ושאלות נפוצות |

המסמכים נכתבו לפי הקוד והאפיון של הפרויקט, ומתארים את מה שהמערכת עושה בפועל.

## החלטות ארכיטקטורה

| נושא | ההחלטה | נימוק |
|---|---|---|
| Vector DB | ChromaDB (מקומי, נשמר לתיקייה `chroma_db`) | חינמי, בלי שרת, חיבור מוכן ל‑LlamaIndex |
| ספרייה | LlamaIndex | דרישת התרגיל |
| חלוקה ל‑Chunks | `SentenceSplitter`, 512 טוקנים | זול, לא חותך משפטים באמצע. חלוקה לפי משמעות יקרה יותר כי היא מחשבת embedding לכל משפט |
| חפיפה | 50 טוקנים (כ‑10%) | מונעת מצב שתשובה נחתכת בין שני chunks, בעלות זניחה |
| ספק API | Google Gemini | שכבה חינמית |
| Top K | 4 | מספיק כדי למצוא מידע שמתפרס על כמה מקומות, בלי להכניס רעש |
| מודל Embedding | `gemini-embedding-001` | חינמי, תומך בעברית, מבחין בין embedding של מסמך לשל שאלה |
| מודל תשובה | `gemini-3.5-flash` | חינמי, מהיר, טוב בעברית |
| הרחבת שאלה | Condense Question | שאלת המשך ("ומתי משלמים?") מנוסחת מחדש לשאלה מלאה לפי היסטוריית השיחה |
| צורת חיפוש | דמיון קוסינוס + סף מינימלי (0.70) | אם אף chunk לא מספיק קרוב לשאלה, הבוט עונה שאין לו מידע במקום להמציא |
| ממשק | Gradio `ChatInterface` | כמה שורות קוד, תמיכה מובנית בימין‑לשמאל |

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `config.py` | כל ההגדרות במקום אחד |
| `models.py` | הגדרת המודלים של Gemini וחיבור ל‑ChromaDB |
| `ingest.py` | קריאת המסמכים, חלוקה ל‑chunks ושמירת הווקטורים |
| `rag.py` | מנוע השיחה: ניסוח השאלה, חיפוש, סינון לפי סף ויצירת תשובה |
| `app.py` | ממשק הצ'אט |
| `data/` | מסמכי הארגון (txt, pdf, docx) |

## הרצה

1. יצירת מפתח API ב‑Google AI Studio.
2. התקנת הספריות:
   ```
   pip install -r requirements.txt
   ```
3. העתקת `.env.example` לקובץ בשם `.env` והדבקת המפתח.
4. הכנסת המסמכים לתיקייה `data`.
5. בניית האינדקס (פעם אחת, ושוב בכל שינוי במסמכים):
   ```
   python ingest.py
   ```
6. הפעלת הבוט:
   ```
   python app.py
   ```
   ופתיחת הכתובת שמודפסת (בדרך כלל http://127.0.0.1:7860).
